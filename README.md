# Sebiston — отдел продаж

Веб-приложение для учёта работы отдела продаж Sebiston: 5 вкладок по рабочим документам отдела.

## Вкладки

**Ввод**
- **Звонки** — входящие звонки и сообщения (Instagram, WhatsApp, Telegram)
- **Офис** — клиенты, обслуженные в офисе
- **Продажи** — реестр сделок: общая сумма и остаток считаются автоматически
- **Хронометраж** — рабочий день менеджера по интервалам

**Отчёты** (считаются из введённых данных, любую ячейку можно перебить вручную)
- **Лиды по дням** — отчёт одного менеджера за месяц

## Проверки
- дубль клиента по номеру телефона
- проведено встреч больше, чем назначено
- пересечение интервалов в хронометраже, простой больше 30% дня
- строка ИТОГО всегда складывается из строк и вручную не заполняется

## Вход
Сайт открывается после входа по логину и паролю; сессия держится 30 дней, кнопка «Выйти» в шапке.
Пароли в коде хранятся только как хэши PBKDF2-SHA256. Это защита от случайных посетителей,
а не от технически подготовленного человека: сайт статический и репозиторий публичный.

## Хранение данных
В этой версии данные хранятся в браузере (localStorage) — у каждого менеджера свои.
Для общей базы отдела нужен бэкенд (Supabase / Firebase) или перенос в Битрикс24.

Выгрузка в Excel — CSV в UTF-8 с разделителем `;`, открывается в Excel без настройки кодировки.

## Киоск регистрации визита — `/visit/`
Отдельная страница для планшета на ресепшене (макет `Sebiston_Autorization`, 1377×1025, масштабируется под экран):
заставка «ВОЙТИ», строительный ролик при простое (`visit/attract.mp4`, можно заменить своим),
форма для ролей Покупатель / Клиент / Брокер / Партнёр, справочники ЖК и целей визита, языки РУС/ТОҶ.

- Отправка заявок в Битрикс24: впишите адрес входящего вебхука `crm.lead.add` в `CONFIG.BITRIX_WEBHOOK`
  в `visit/index.html`. Пока он пустой, заявки копятся в очереди браузера и уйдут, когда адрес появится.
- Подтверждение номера по SMS и поиск клиента в базе пока демонстрационные (помечены `DEMO`).
